# Budget per command

Generated by `tests/budget.rs`, which fails when this file differs from what its scenarios spend on the stand-in Core; `UPDATE_BUDGET=1 cargo test --test budget` rewrites it. Each method's cost is opcore's decision record 1, in the opcore source `Cargo.lock` pins. Each command is a new process: its first vault call after signing in spends one read and one of the account's daily requests more. A call 1Password refuses spends nothing.

| Command | Core calls | Reads | Writes | Account requests |
|---|---|---|---|---|
| `list`, the first Sync on a new host | `init_client`, `VaultsList`, `ItemsList` | 2 | 0 | 1 |
| `put` of a new Secret | `init_client`, `ItemsList`, `ItemsCreateAll` | 2 | 1 | 1 |
| `put` of what the Secret holds | `init_client`, `ItemsList` | 1 | 0 | 1 |
| `put` of a changed Field | `init_client`, `ItemsList`, `ItemsGetAll`, `ItemsPut` | 3 | 1 | 1 |
| `list` from an old Copy | none | 0 | 0 | 0 |
| `get` from an old Copy | none | 0 | 0 | 0 |
| `env` from an old Copy | none | 0 | 0 | 0 |
| `get` of a Secret the Copy lacks, made on another host | `init_client`, `ItemsList`, `ItemsGetAll` | 1 | 0 | 1 |
| `get --fresh`, the Secret changed on another host | `init_client`, `ItemsList`, `ItemsGetAll` | 1 | 0 | 1 |
| `mv` | `init_client`, `ItemsList`, `ItemsGetAll`, `ItemsPut` | 3 | 1 | 1 |
| `put` of a changed Field while 1Password refuses writes (it waits) | `init_client`, `ItemsList`, `ItemsGetAll`, `ItemsPut` | 1 | 0 | 1 |
| `list --fresh` that pushes that waiting write | `init_client`, `ItemsList`, `ItemsGetAll`, `ItemsPut` | 3 | 1 | 1 |
| `rm` | `init_client`, `ItemsList`, `ItemsDeleteAll` | 2 | 1 | 1 |
| `doctor` | none | 0 | 0 | 0 |
| `put` of a new Secret, the first Sync on a new host | `init_client`, `VaultsList`, `ItemsList`, `ItemsCreateAll` | 3 | 1 | 1 |
